# StMaHack - SPA приложение с AI-помощником

## Описание
Это Single Page Application (SPA) с интегрированным AI-помощником Гошей. Приложение позволяет пользователям просматривать каталог приложений и получать помощь от AI-ассистента.

## Установка и запуск

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Запуск сервера
Вариант 1 - через Python:
```bash
python ai_server.py
```

Вариант 2 - через bat файл (Windows):
```bash
start_server.bat
```

### 3. Открытие приложения
После запуска сервера откройте браузер и перейдите по адресу:
```
http://localhost:8000
```

## Функциональность

### Основные возможности:
- Просмотр каталога приложений
- Навигация между страницами приложений
- Поиск по приложениям
- Меню настроек

### AI-помощник Гоша:
- Доступен через меню (кнопка "AI-Помощник")
- Помогает в поиске и подборе приложений
- Специализируется на российских приложениях
- Поддерживает историю диалога

## Использование AI-помощника

1. Нажмите на кнопку меню (три полоски) в правом верхнем углу
2. Выберите "AI-Помощник"
3. В открывшемся окне введите ваш вопрос
4. Гоша поможет вам найти подходящие приложения

## Технические детали

- **Frontend**: HTML, CSS, JavaScript (Vanilla JS)
- **Backend**: FastAPI (Python)
- **AI**: Groq API с моделью Llama 3.1
- **Архитектура**: SPA с модальными окнами

## Файловая структура
```
Hackath/
├── index.html          # Основной HTML файл
├── styles.css          # Стили приложения
├── ai_server.py        # Python сервер с AI
├── requirements.txt    # Зависимости Python
├── start_server.bat    # Скрипт запуска (Windows)
```

## Удаление старой папки
После успешного запуска и тестирования можно безопасно удалить папку `StMaHack-AI-ASS-1`, так как вся функциональность интегрирована в основное приложение.
