# StMaHack - SPA приложение с AI-помощником

## Описание
Это Single Page Application (SPA) с интегрированным AI-помощником Гошей. Приложение позволяет пользователям просматривать каталог приложений и получать помощь от AI-ассистента.

## Установка и запуск

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Настройка API ключа
Для работы AI-помощника Гоши необходим API ключ от Groq:

1. Зарегистрируйтесь на https://console.groq.com/
2. Создайте новый API ключ
3. Скопируйте ключ из файла `.env` и вставьте свой:
```
GROQ_API_KEY=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
```

### 3. Настройка VPN (обязательно)
**ВАЖНО**: Для работы AI-помощника необходимо использовать VPN, так как Groq API может быть недоступен в некоторых регионах.

Рекомендуемые настройки VPN:
- Выберите сервер в США или Европе
- Убедитесь, что VPN активен перед запуском сервера
- Проверьте соединение на https://console.groq.com/

### 4. Запуск сервера
Вариант 1 - через Python:
```bash
python ai_server.py
```

Вариант 2 - через bat файл (Windows):
```bash
start_server.bat
```

### 5. Открытие приложения
После запуска сервера откройте браузер и перейдите по адресу:
```
http://localhost:8000
```

### 6. Проверка работы AI
Для диагностики проблем с AI откройте:
```
http://localhost:8000/api/health
```

## Функциональность

### Основные возможности:
- Просмотр каталога приложений
- Навигация между страницами приложений
- Поиск по приложениям
- Меню настроек

### AI-помощник Гоша:
- Доступен через кнопку 🤖 или меню "AI-Помощник"
- Помогает в поиске и подборе приложений
- Специализируется на российских приложениях
- Поддерживает историю диалога
- **Требует VPN для работы**

## Использование AI-помощника

1. **Убедитесь, что VPN включен**
2. Нажмите на кнопку 🤖 в правом нижнем углу или выберите "AI-Помощник" в меню
3. В открывшемся окне введите ваш вопрос
4. Гоша поможет вам найти подходящие приложения

### Устранение проблем с AI:
- Проверьте статус внизу модального окна AI
- Убедитесь, что VPN активен
- Проверьте консоль сервера на наличие ошибок
- Откройте `/api/health` для диагностики

## Технические детали

- **Frontend**: HTML, CSS, JavaScript (Vanilla JS)
- **Backend**: FastAPI (Python)
- **AI**: Groq API с моделью Llama 3.1 (требует VPN)
- **Архитектура**: SPA с модальными окнами

Приложение адаптировано для различных устройств:

- **Планшеты** (501-1024px): Увеличенные элементы и отступы
- **Десктопы** (1025px+): Полноценный интерфейс с центрированным контентом

## Возможные проблемы

### AI не работает:
1. Проверьте наличие файла `.env` с правильным API ключом
2. Убедитесь, что VPN включен и работает
3. Проверьте `/api/health` для диагностики
4. Посмотрите консоль сервера на наличие ошибок

### Проблемы с интерфейсом:
- Очистите кэш браузера
- Убедитесь, что сервер запущен на порту 8000
- Проверьте, что открываете `http://localhost:8000`, а не файл напрямую
